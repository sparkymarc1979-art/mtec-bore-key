MTEC Quote Tool - No Password Version

Admin Settings:
- Click Admin Settings to open/close the settings area.
- No password is used in this version.

Logo:
1. Put your logo image in this folder.
2. Rename it exactly to: logo.png
3. Make sure Windows is not hiding the extension.
   It must be logo.png, not logo.png.png.
4. Refresh the browser.

If the logo still does not appear:
- Open the folder and check index.html and logo.png are in the same folder.
- Try a simple lowercase filename: logo.png
- Hard refresh browser: Ctrl + F5
- If hosted, re-upload logo.png alongside index.html.
